Join with Prism Launcher

  1. Install Prism Launcher 11 and Java 25.
  2. Create a 26.1.2 instance with Fabric 0.20.1 (4–6 GB memory).
  3. Put packwiz-installer-bootstrap.jar in the instance's .minecraft/ folder.
  4. Edit → Settings → Custom commands, pre-launch: 
    "$INST_JAVA" -jar "$INST_MC_DIR/packwiz-installer-bootstrap.jar" -g -s client https://mc-pack.han-diatonic.uk/pack.toml
  5. Launch once. Mods and client configs install and stay in sync on every launch.
